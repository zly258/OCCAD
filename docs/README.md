# OCCAD Documentation

This directory is the single design and development baseline for the OCCAD repository. It is based on a second-pass analysis of `zly258/OCCTBIM-Source` and the current OCCAD implementation, but defines OCCAD's own .NET/WPF contracts rather than copying Qt implementation details.

- 中文：[`zh-CN/README.md`](zh-CN/README.md)
- English: [`en-US/README.md`](en-US/README.md)

The language trees mirror each other. The normative shell is native WPF classic `Menu + ToolBar + Docks + StatusBar + non-modal ToolPanel`; Ribbon is not part of the target architecture.
